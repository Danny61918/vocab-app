# P5 — 家長診斷 · REQUIREMENTS

> 對應 spec §4.4、§4.6、TASK-07。相依：P2。風險：低。

## 背景
家長需要能區分孩子的**錯誤類型**（拼寫 / 語意 / 語境）以對症幫忙，但這些資訊**不得對孩子顯示**（Prime Directive：不評價她、不施壓）。

## 功能需求
- **FR-1 隱藏家長入口**：AnalyticsDashboard 標題長按（~1.5 秒）解鎖家長診斷面板；孩子平常看不到。
- **FR-2 錯誤類型診斷**：用 `answerLog` 按 gameType 聚合錯誤率，給白話診斷：cloze 高→拼寫弱、sentence_cloze 高→語境弱、matching 高→中英對應弱。
- **FR-3 逾期字清單**：列出目前 `dueDate` 已過的字（依逾期天數排序）。
- **FR-4 每日投入時間**：由 answerLog 的 responseMs 依日期加總。

## 非功能需求
- **NFR-1**：診斷/彙總為純函式、可 Vitest 測。
- **NFR-2 孩子端零可見**：面板僅在長按解鎖後出現；預設隱藏；無排名、無退步警示。

## Out of Scope
- 不改現有「學習成效分析」既有卡片的行為（只新增家長面板）。
- 不上雲（P6）。

## GATE
- 無外部 gate。長按秒數與是否預設隱藏採本設計預設，最終手動驗收可調。
