# ADR-001 — 採固定 Leitner 級距，不用 SM-2

- 狀態：Accepted
- 日期：2026-08-02
- 脈絡階段：P1 SRS 核心引擎

## 脈絡

v2.0 要把假 SRS 換成真到期日制間隔複習。間隔演算法有兩條路：動態的 SM-2（SuperMemo，依作答品質 0–5 計算 easiness factor 與可變間隔），或固定級距的 Leitner box（答對進盒、答錯回盒，各盒對應固定間隔）。使用者是 8 歲兒童，家長需能理解並依段考週期微調。

## 決策

採**固定 Leitner 級距**：`BOX_INTERVALS = [0, 1, 3, 7, 14, 30]`（天），boxLevel 0..5。答對跨日進一盒、答錯退回 box1。

## 理由

- **可解釋性**：家長一眼看懂「這個字下次 7 天後回來」，SM-2 的 EF/品質分對非技術家長是黑箱。
- **可微調**：級距是一個常數陣列，能依段考週期直接調（如週二小考前保證回鍋），符合 spec §7 GATE。
- **足夠**：單字量與使用場景不需要 SM-2 的精細度；固定級距的記憶效果對此年齡層已足夠（spec §8 ASSUMPTION，4 週答對率驗證）。
- **好測試**：固定級距 + 注入式時間 → E2E-2（+1/+3/+7）可確定性驗證；SM-2 的浮點 EF 難寫穩定測試。

## 後果

- 正面：實作簡單、測試穩定、家長可控、可解釋。
- 取捨：喪失 SM-2 的個別字自適應（某些字對某人特別難時無法自動拉長/縮短）。以「答錯一律退 box1」的強懲罰部分補償。
- 可逆性：若 4 週驗證顯示固定級距不足，可在 v2.x 以相同 `VocabMastery` 欄位擴充 easiness factor 升級為 SM-2，資料模型不需砍掉重來。
